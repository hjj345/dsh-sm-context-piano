# sm-context-piano

DeepSeek Harness Web GUI 的 Codex 式对话琴键导航插件。

插件在聊天内容左侧显示一条紧凑横线轨道。琴键只代表用户消息和模型可见文本输出：连续模型输出合并，遇到工具、编辑、推理或其他非输出内容后重新分段。默认最多显示当前节点前后的 20 根琴键，点击边界琴键即可继续浏览更早或更晚的节点。

本插件只负责导航和预览：不修改会话、不裁剪模型上下文、不注入系统提示，也不开放额外 HTTP 接口。

## 当前功能

- **纯输出节点**：只生成用户消息和模型可见文本琴键，完全排除 tool/edit/read/reasoning 和内部状态。
- **连续输出合并**：相邻且未被非输出内容打断的模型文本合并为一根琴键；不连续输出保持独立。
- **固定琴键窗口**：默认高度 230px、中心间距 12px、琴键粗细 2px、最多 20 根，不为容纳全部历史而压缩。
- **活动节点居中**：以当前阅读节点为中心显示前后节点；点击顶部或底部琴键后自动换出更早或更晚的窗口。
- **连续悬停波形**：整条轨道都是命中区域，鼠标位于横线间隙时仍可连续选择最近节点。
- **Codex 式预览**：白色/深色浮层显示节点标题和正文摘要，自动避开窗口边界。
- **快速定位**：点击轨道或按 Enter，滚动到目标消息起始位置。
- **阅读位置同步**：滚动聊天时，当前段落琴键立即加深并加长。
- **增量更新**：流式回复和历史加载不会清空重建全部琴键，已有 DOM 节点和悬停状态会保留。
- **键盘操作**：方向键、Home、End、Enter、Space 和 Escape 可完成选择与跳转。
- **主题与动效**：跟随 DSH 明暗主题，并遵守 `prefers-reduced-motion`。
- **完整卸载**：插件卸载后移除 DOM、样式、监听器、Observer、定时器和动画帧。

## 设置

安装后在 DSH 设置弹窗左侧打开一级导航 **琴键导航**。该项按顺序位于官方 **Agent 预设** 下方，名称跟随 DSH 全局语言，导航图标遵循 DSH 对第三方设置项的默认齿轮回退。

可即时生效并由 DSH 持久化的设置：

- 启用或停用琴键导航；
- 设置页语言：简体中文（默认）、English、繁體中文；
- 琴键高度/粗细：1–4px，默认 2px；
- 琴键中心间距：6–18px，默认 12px；
- 最大显示琴键数量：5–30，默认 20。

语言切换只作用于插件设置页，立即生效且重启后保留；DSH 一级导航名称和琴键轨道无障碍名称仍跟随 DSH 全局语言。轨道总高度自动按 `(最大数量 - 1) × 间距 + 琴键高度` 计算，例如默认值为 `(20 - 1) × 12 + 2 = 230px`。设置页提供恢复默认值操作，并显示版本 `v1.0`、发布日期、作者、邮箱、安装命令及待公布的 GitHub、npm 状态。

## 实现边界

- 当前实现依赖 DeepSeek Harness ChatView 的 `[data-chat-flow]`、`[data-chat-anchor-key]` 和 `[data-conversation-scroll]` DOM 锚点。
- 设置通过 DSH 官方 `settings.section` 与 settings namespace 接入，不使用浏览器私有存储。
- 琴键只覆盖当前已加载的历史；尚未通过“加载更早消息”进入 ChatView 的记录不会提前生成琴键。
- 工具、编辑、命令、推理和内部状态不会创建琴键，也不会在悬停后出现。
- 同一 DOM 行内被非输出 block 分隔的多段模型文本可生成多根琴键，但受限于 Harness 行级锚点，点击时均定位到该消息行起点。
- 预览始终通过 `textContent` 写入，保留纯文本换行，不执行会话内容中的 HTML。

# sm-context-piano 完成与验收记录

## 最终目标

在 DeepSeek Harness 中实现 Codex 式集中琴键导航：

- 只显示用户消息和模型可见文本输出；
- 连续模型输出合并，非连续输出分开；
- 工具、编辑、命令、推理及内部状态完全隐藏；
- 固定 346px 高度和 18px 间距；
- 最多显示当前节点前后的 20 根琴键；
- 通过选择窗口边界继续浏览更早或更晚节点。
